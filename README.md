# HumanType

Эмулирует «человеческий» набор текста в любом приложении.

1. Вставьте текст в приложении, нажмите «Показать панель» (приложение само попросит нужные разрешения).
2. На панели нажмите ⌨ и выберите HumanType (один раз).
3. Откройте нужное приложение, нажмите на поле ввода и нажмите ▶ на панели.

Панель: ✥ перетащить, ▶/■ старт/пауза, долгое нажатие на ▶ — заново с начала, ⌨ сменить клавиатуру, ⚙ открыть приложение, ✕ закрыть.
